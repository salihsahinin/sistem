# raporlar/diger/

**Ne var:** tarihsiz/tekil sınıflandırılamayan raporlar — 4 dosya (transkript, sunum, teslim).
**Nasıl gezilir:** sabit adlandırma kalıbı yok, dosya adı kendini açıklar; ay alt-klasörü yok.
**Üretici:** elle/oturum akışı.
**Arşiv kuralı:** silme yok (m.8); bayat dosya `arsiv/` altına taşınır.
