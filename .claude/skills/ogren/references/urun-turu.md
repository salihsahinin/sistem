Koşul: her kurs/şerit bittiğinde öğrenilenle depoda geliştirme yapılır, yalnız ölçülebilir iyileşme varsa.

1. **(a) Aday listesi:** kapanış dersinde, ders boyunca biriken "⌥ Jarvis notu" bloklarından (öğrenilen mekanizma → depodaki boşluk).
2. **(f) Güncel-pratik taraması (önce):** dar canlı tarama, tek atlas işçisi, bütçe 10-15 tur, soru "bu mekanizma 2026'da üretimde nasıl kullanılıyor, hangi araç/desen standart"; AS-OF damgalı (Karar 68). Ders içi "⌥ Jarvis notu" bağları bu taramayla teyit edilmeden ürün olmaz.
3. **(b) 3 model (m.37):** token × zaman × beklenen-kalite sayısal; biri zorunlu "hiçbiri — iyileşme kanıtı yok"; önerilen ilk sırada.
4. **(c) Metrik önce:** mevcut değer + hedef + ölçen script (m.39; hazırı temel al).
5. **(g) Skill-oluşturma sorusu:** her aday için "bu öğrenme bir skill'e döner mi?" — skill = tekrarlanan, koşullu, araç-zincirli prosedür (K0 Y1/Y3). Kavram/teori dersi doğrudan skill olmaz; **icra-türü eşlemesi:** her kavram için "hangi icra türünde (ritüel / orkestratör / işçi emri / ingest / öğrenme) hangi bağlamda kullanılır" satırı; eşleme varsa o icra türü için aday (→ `skill-kapisi` K0-K3, eval-önce, baseline zorunlu), eşleme yoksa `BEKLET` (kutuda sayaçla). Yerleşim: jarvis işi → `.claude/skills/`; staj/işyeri işi → staj reposu (md.49; jarvis'te yalnız ad + pointer), staj bilgisi genelleştirilmiş formatta (Karar 96 M6).
6. **(d) Hüküm:** Salih'in, masada (`karar-masasi`); yan oturum aday listesi + metrik taslağı üretir, hüküm vermez (m.41). Hüküm → İB kalemi → icra ana-sırada; ürün = script/skill/kural + ölçüm.
