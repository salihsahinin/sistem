# Öğrenme şeritleri kuralı (yalnız `ogrenme/` altındaki dosyalarla çalışırken yüklenir; Karar 96 M1 üç-yuva, 2026-09-15)

- Protokolün tamamı `ogrenme/README.md` (oturum adımları 0-6) ve kurs README'sindedir; bu dosya yalnız sabit frenleri taşır.
- Ders iskeleti: `kuyruk/skill-deneme/ogren/SKILL.md` v0.1 (PROBE → PLAN DAG → TEACH kutu → CLOSE). Her kutu başlığında sektördeki güncel İngilizce ad, AS-OF damgalı, ders başında canlı teyit.
- Her derste ≥1 formül: tanım + sembol tablosu + elle işletilmiş sayısal örnek (Karar 73).
- Kamu veri ve kamu görev setleri; şirket/staj verisi kullanılmaz (md.49).
- Ders kaydı `dersler/YYYY-MM-DD-XN-konu.md`; ilerleme tablosu güncellenir; kapsül/pano/defter'e yazılmaz (ana-sıra işler).
- Seri sonu = ürün turu (README adım 5-6): aday listesi → 3 model (biri "hiçbiri") → güncel-pratik taraması → skill-oluşturma sorusu (g) → Salih hükmü masada.
- Yan oturum: kendi branch'i, `git add <yol>`, seans sonunda push + PR; merge ana-sıra (Karar 95).
