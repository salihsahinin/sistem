# Token×Zaman

**Tanım:** Bir işin iki bağımsız maliyet ekseni — *token* = harcanan toplam token maliyeti (kademeli: az/orta/çok, proje büyüklüğüne göre) · *zaman* = duvar-saati süresi (kademeli: kısa/uzun, proje büyüklüğüne VE eldeki zamana göre).
**Durum:** GÜNCEL · **Son teyit:** 2026-07-12 (tüzük dipnotu, Salih imzalı) · **Kaynaklar:** tüzük dipnot + m.17/21/29/31 · **Güven:** YÜKSEK (imzalı tanım, çelişen kayıt yok)

## Çekirdek
İki eksen bilinçli olarak ayrıdır çünkü ikisi farklı şeylerden fedakarlık ettirir: token = para/bütçe, zaman = Salih'in bekleyişi ve pistin (6 ay) tükenişi. Aynı iş farklı kombinasyonlarla yapılabilir; Salih'in feedback'leri hangi kombinasyonun denenerek değiştirileceğini tetikler (V15 hattı; m.31 üç-kart deseni bu tabana oturur).

**Kanonik örnek (damıtılmış; ham senaryo: bu oturumun K-013 koşusu):** Aynı araştırma işi iki yolla yapılabilirdi — 2 paralel ajan: ~166K token, ~7 dk (token: orta-çok, zaman: kısa) · tek ajan seri: daha az token, ~2 kat süre (token: orta, zaman: uzun). Deadline yakınsa birincisi, bütçe darsa ikincisi seçilir. Seçim işin değil, PARAMETRELERİN fonksiyonudur.

## SOP — iş planlarken
1. Proje/görev büyüklüğünü kaba sınıfla (küçük/orta/proje-ölçekli — m.25).
2. Token kademesini seç (az/orta/çok) → bütçe sınırı.
3. Zaman kademesini seç (kısa/uzun) → eldeki takvimden.
4. Kombinasyonu ve gerekçeyi kaydet (görev emri/rapora 1 satır) — bu satır V28 etiketleme verisinin hammaddesi.
5. Salih feedback verirse: parametreyi güncelle, FARKLI kombinasyon dene (V15); kart değişimi gerekiyorsa m.31.

## Gotchas
- **Ucuz model ≠ ucuz iş:** ölçülmüş vaka — ucuz model analitik işte daha çok tur yaktı, toplam token DAHA kötü (her tur = bağlam yeniden okunur). (K-013 raporu)
- **Paralellik vergisi:** takım, aynı işte tek ajanın ~3-4 katı token; kazanç yalnız iş gerçekten paralelleşiyorsa. Kural: paralellik kazancı > koordinasyon vergisi değilse takım kurma.
- **Duvar-saati ≠ düşünme süresi:** bekleme (Salih onayı, API, senkron) süreyi şişirir ama token yakmaz — ikisini ayrı oku (#24b formül girdisi).
