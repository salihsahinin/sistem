# raporlar/

**Ne var:** teslim edilen raporlar, insan-yüzü çıktılar, hareket günlükleri.
**Nasıl gezilir:** `YYYY-MM/` ay klasörleri (`2026-07/`, `2026-08/`, `2026-09/`) tarihli KONU raporlarını (`YYYY-MM-DD-<konu>.md/.html`) taşır; sınıflara ayrılmış alt-dizinler kendi README'sinde açıklanır — `seans/` (seans teslimi), `vardiya/` (vardiya teslimi), `hareket/` (hareket kütüğü), `masa/` (karar-yüzeyi HTML), `gorsel/` (öğretim görselleri), `jarvis/` (JARVIS öz-mimari çıktıları), `diger/` (tarihsiz tekiller). Aynı ay-klasörü düzeni `cc/rapor/` ve `cc/gorev/` için de geçerlidir (kendi README'lerinde açıklı).
**Üretici:** çoğunlukla seans/vardiya ritüelleri + ilgili skill/script; tarihli konu raporları elle/oturum akışıyla düşer.
**Arşiv kuralı:** silme yok (m.8); bayat rapor `arsiv/` altına taşınır.
