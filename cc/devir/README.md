# cc/devir/

**Ne var:** oturumlar/modeller arası devir (handover) dosyaları (4 dosya).
**Nasıl gezilir:** `devir-YYYY-MM-DD-<konu>.md` adı; ay alt-klasörü yok.
**Üretici:** elle/oturum akışı (seans kapanışı ya da yan-oturum geçişi sırasında).
**Arşiv kuralı:** silme yok (m.8); bayat devir dosyası `arsiv/` altına taşınır.
